## 📋 Descripción del Proyecto
El **STR-002 H3 v3.0** es un vehículo aéreo no tripulado agrícola (MTOW ≈ 28.5 - 29.5 kg) diseñado para la aplicación de tasa variable (VRA) de agroquímicos en cultivos de alta densidad en Úrsulo Galván, Veracruz.

## 🛠️ Especificaciones Técnicas
* **MTOW:** 28.5 - 29.5 kg
* **Payload:** 10.0 L (Tanque HDPE)
* **Chasis:** Fibra de Carbono 3K (3.0 mm) + Abrazaderas H3 7075-T6
* **Alimentación:** Bus 12S LiPo (50.4V pico) + QS8-S Anti-Spark
* **Aviónica:** Cube Orange+ / RTK Dual u-Blox ZED-F9P / Radar mmWave 77 GHz
* **Hidráulica:** 4x Electroválvulas NC 24V distribuidas en puntas + Caudalímetro YF-S201 (450 p/L)
