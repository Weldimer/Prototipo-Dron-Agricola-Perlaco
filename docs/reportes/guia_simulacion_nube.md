# 🚁 Guía de Simulación y Validación en la Nube — STR-002 H3 v3.5

Este documento detalla los procedimientos para ejecutar simulaciones completas del octocóptero coaxial X8 de 29 kg utilizando exclusivamente herramientas gratuitas en la nube (Google Colab, GitHub Codespaces, DroneSim Cloud y SIMNET) sin requerir hardware local costoso.

---

## ☁️ Opciones de Simulación Disponibles en el Repositorio

1. **Google Colab (`/simulation/colab/`)**: Ideal para procesar modelos numéricos, simulación de misiones VRA por variedad en Úrsulo Galván y generación de gráficas de rendimiento mediante bibliotecas de Python (`pandas`, `matplotlib`, `plotly`).
2. **GitHub Codespaces**: Entorno Linux en la nube vinculado al repositorio para compilar y ejecutar ArduPilot SITL nativo con los parámetros del STR-002.
3. **Simuladores Visuales 3D (DroneSim / SIMNET)**: Plataformas recomendadas para obtener capturas de pantalla y videos del dron en vuelo para enriquecer el pitch deck de inversión.
